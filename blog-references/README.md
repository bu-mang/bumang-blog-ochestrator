# 블로그 레퍼런스 글 모음

이 폴더는 **블로그 글의 톤앤매너 기준이 되는 레퍼런스 글**을 모아두는 곳이다.

새 글을 쓸 때 에이전트는 [../BLOG_GUIDE.md](../BLOG_GUIDE.md)의 규칙을 따르되,
**여기 있는 글들을 먼저 읽고 그 문장 호흡·어휘·구성**을 흉내 내야 한다.
가이드 문서가 "규칙"이라면 이 폴더의 글들은 "족보"이다. 둘이 충돌하면 레퍼런스 쪽 실제 문장을 우선한다.
